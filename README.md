# LORELAB

**Find the story. Cook the story.** 🔥

LORELAB is a personal AI-powered history content research and production system.

The goal is simple:

> Tap **LET'S COOK 🔥**, choose **Short** or **Long**, and get a researched history story packaged for content creation.

## Planned pipeline

1. Discover current trends and historical topics.
2. Score topics for relevance, curiosity, emotional pull, visual potential, and competition.
3. Research and fact-check the selected story.
4. Generate a high-retention script for the chosen format.
5. Break the script into scenes.
6. Generate image and video prompts for each scene.
7. Generate titles, descriptions, keywords, hashtags, and thumbnail concepts.
8. Present every output as an independently copyable block.

## Project status

🚧 **Private-use MVP in active development.**

The repository is public, but credentials, personal channel data, and production environment variables must never be committed.

## Development

The stack and architecture are being built incrementally during the initial 72-hour MVP sprint.

## Security

Copy `.env.example` to your local environment and fill in your own credentials. Never commit `.env`, `.env.local`, API keys, tokens, or private channel data.
